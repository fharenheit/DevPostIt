# Monaco 편집기 설계 변경

2026-11-01 사용자 요청과 선택에 따른 작업 3 변경입니다.

- Markdown 편집은 Monaco 소스 편집과 읽기 전용 렌더링 미리보기를 제공합니다. 기존 WYSIWYG 편집 요구와 TipTap/Milkdown 후보 비교를 이번 범위에서 대체합니다.
- 원문을 편집 모델과 별도로 유지해 열기·닫기·보기 전환만으로 원문이 변하지 않게 합니다. 실제 편집 후에는 Monaco의 본문과 줄바꿈 형식을 사용합니다.
- 표·체크리스트·코드·제목·목록을 렌더링합니다. HTML은 실행하지 않고 문자로 표시하며 원격 이미지와 외부 탐색은 차단합니다. 미지원 확장 구문도 소스에 보존합니다.
- D2 Ligature를 기본으로, JetBrains Mono와 시스템 고정폭 글꼴을 선택할 수 있습니다. 합자는 기본 활성화하며 사용자가 끌 수 있습니다. 두 글꼴은 공식 배포본과 라이선스를 함께 번들링해 오프라인에서 제공합니다.
- 보기 전환 중 조합 중인 한글은 조합 완료 전까지 전환을 지연합니다. 자동화한 합성 조합 이벤트와 브라우저 IME 주입을 검증하되 실제 Windows 한글 IME 수동 검증과 구분합니다.
- `Editor.load(noteId, markdown, revision)`, `setMode('source'|'preview')`, `getDraft()`를 제공합니다. WPF 브리지 연결은 작업 4에서 진행합니다.
- 대안: Monaco+별도 WYSIWYG는 두 편집 모델 간 동기화와 손실 방지가 필요합니다. 사용자는 Monaco+미리보기를 선택했습니다.
