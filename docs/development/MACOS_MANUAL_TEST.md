# macOS 수동 시험 절차

macOS 5단계의 끝나는 조건입니다. 실제 마우스, 키보드, IME, 시스템 권한이 필요해 자동 시험(MacSmoke, Playwright)이 확인하지 못하는 항목만 다룹니다. 결과는 [HANDOFF.md](HANDOFF.md)에 기록합니다.

## 준비

저장소 루트에서 빌드하고 시험용 데이터로 실행합니다. 환경 변수 없이 실행하면 실제 메모 폴더를 쓰므로 반드시 지정합니다.

```zsh
export DOTNET_ROOT="$PWD/.tools/dotnet" DOTNET_CLI_HOME="$PWD/.tools/cli" DOTNET_NOLOGO=1 DOTNET_CLI_TELEMETRY_OPTOUT=1
export PATH="$PWD/.tools/dotnet:$PWD/.tools/node/node-v24.22.1-darwin-arm64/bin:$PATH"
dotnet build src/DevPostIt.Mac --no-restore
DEVPOSTIT_DATA_DIR="$PWD/.tools/manual-test/data" DEVPOSTIT_WEBKIT_STORE=$(uuidgen) \
  src/DevPostIt.Mac/bin/Debug/net10.0-macos/osx-arm64/DevPostIt.app/Contents/MacOS/DevPostIt.Mac
```

- 앱은 메뉴 막대 아이콘에서 시작합니다. 클릭하면 메뉴가 열리고, 새 메모는 메뉴의 ‘새 메모’로 만듭니다.
- `scripts/macos-signing/create-certificate.sh`로 인증서를 만들면 빌드가 바뀌어도 권한이 유지됩니다. 임시 서명으로 빌드하면 빌드할 때마다 화면 기록과 손쉬운 사용 권한이 초기화될 수 있습니다. 허용했는데도 캡처가 실패하면 시스템 설정에서 항목을 지우고 다시 허용합니다.

## 절차

| # | 절차 | 기대 결과 |
| --- | --- | --- |
| 1 | 메뉴의 ‘화면 캡처’와 ⌃⇧⌘C를 각각 실행 | 권한이 없으면 이유를 알리고 시스템 설정으로 안내합니다. 허용한 뒤 앱을 다시 실행해야 할 수 있습니다 |
| 2 | 창 위에 커서를 올린 뒤 클릭, 그다음 드래그로 영역 선택 | 강조선이 보이고 고른 영역이 찍힙니다 |
| 3 | 캡처 중 Esc, 오른쪽 클릭, 60초 대기를 각각 시험 | 캡처가 취소되고 오버레이가 사라집니다 |
| 4 | 주석 창에서 화살표, 사각형, 모자이크, 글자(한글 포함)를 넣고 실행 취소 후 메모에 넣기 | 입력이 정상이고 그림이 메모 미리보기에 표시됩니다 |
| 4-1 | 주석을 넣고 ‘클립보드에 넣기’를 누른 뒤 다른 앱에 붙여 넣기 | 주석이 들어간 그림이 붙고, 메모는 바뀌지 않습니다 |
| 4-2 | 주석 창에서 상하좌우 테두리에 커서를 올린 뒤 끌고, 실행 취소 후 다시 끌어 메모에 넣기 | 커서가 크기 조절 모양으로 바뀌고, 잘릴 부분이 어두워지며, 고른 영역만 메모에 들어갑니다 |
| 5 | 메모에서 ⌘⇧C, 이미지 붙여넣기, 미리보기에서 이미지를 눌러 50% 선택 | 삽입과 크기 변경이 정상입니다 |
| 6 | 설정(⌘,), 검색(⌘⇧F), 도움말, 정보, 포맷터 열기 | 각 창이 열리고 설정이 열린 메모에 반영됩니다 |
| 7 | 메모 이름 변경, 마인드맵, 할 일, 달력에 한글 입력(조합 중 Enter 포함) | 글자가 깨지거나 중복되지 않습니다 |
| 8 | 할 일에 1~2분 뒤 알림 설정 | 알림이 표시되고 누르면 창이 열립니다 |
| 9 | 설정에서 백업 후 복원 | 앱이 다시 시작되고 내용이 복원됩니다. 시험용 데이터 폴더를 계속 쓰는지 확인하고, 실제 메모가 보이면 중단합니다 |
| 10 | PDF 저장, 쓰지 않는 이미지 정리 | PDF가 저장되고, 정리한 파일이 실제 휴지통으로 옮겨집니다 |

## 환경이 있을 때만

| 조건 | 절차 | 기대 결과 |
| --- | --- | --- |
| 모니터 2대 이상 | 모니터를 걸친 영역과 배율이 다른 모니터에서 캡처 | 고른 영역이 어긋나지 않습니다 |
| draw.io Desktop 설치 | 다이어그램을 추가해 저장하고 메모로 돌아오기 | draw.io에서 열리고 저장한 그림이 미리보기에 다시 표시됩니다 |
