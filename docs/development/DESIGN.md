# 설계 결정

지금 코드에 남아 있는 결정과 그 이유만 적습니다. 지켜야 할 동작은 [AGENTS.md](../../AGENTS.md), 현재 상태는 [HANDOFF.md](HANDOFF.md)에 있습니다. 예전 계획과 작업 기록은 Git 기록에 있습니다.

## 구성

- WPF 창 안에 WebView2로 `editor-web` 페이지를 띄웁니다. 페이지는 메모(`index.html`), 설정(`settings.html`), 검색(`search.html`)입니다.
- 편집은 Monaco 소스 편집과 읽기 전용 미리보기입니다. 처음 계획한 WYSIWYG는 편집 모델 두 개를 맞춰야 해서 버렸습니다.

## 저장

- Markdown 파일이 정본이고 SQLite는 다시 만들 수 있는 검색 인덱스입니다.
- 저장 순서는 복구 저널, Markdown 파일(임시 파일 후 원자적 교체), 인덱스, 저널 정리입니다. 파일 저장에 실패하면 이전 파일과 초안을 유지합니다.
- 저장 직전에 파일 지문을 비교합니다. 외부 변경이 있으면 저장하지 않은 입력이 없을 때 다시 읽고, 있으면 외부 내용을 ‘(외부 변경)’ 메모로 보존합니다.
- X는 사본을 먼저 쓴 뒤 휴지통(`.hunmin/trash`)으로 옮기므로 어느 단계에서 실패해도 메모가 남습니다.
- 기본 위치는 `%LOCALAPPDATA%\DevPostIt\Data`입니다. 이전 위치에서 옮길 때는 복사하고 SHA-256으로 검증한 뒤 이름을 바꾸며, 원본은 지우지 않습니다.
- 백업은 파일별 해시 목록을 넣은 zip입니다. 복원은 검증 후 재시작 때 교체하고 이전 데이터는 `before-restore` 폴더로 옮깁니다.

## 검색

- unicode61은 공백 없는 한글 단어 안을 찾지 못하고, trigram은 1~2글자를 찾지 못합니다. 그래서 3글자 이상은 trigram으로 후보를 찾아 `instr`로 확인하고, 1~2글자는 `instr`로 훑습니다. 짧은 검색어는 큰 저장소에서 느릴 수 있습니다.
- 검색어는 리터럴 부분 문자열이며 연산자로 해석하지 않습니다. 시작할 때 전체 메모를 인덱스에 맞춥니다.
- 손상된 DB는 일반 작업에서 자동으로 초기화하지 않습니다.

## 보안

- 페이지는 경로를 보내지 않습니다. 파일 경로는 앱이 메모 ID로 정하고, 브리지가 출처, ID, 리비전, 허용 필드, 크기를 검사합니다.
- 외부 리소스 요청은 모두 막습니다. 예외는 앱 페이지와 앱이 저장한 형식의 이미지(`devpostit-assets.local`)뿐입니다. 이 호스트는 `DenyCors`로 등록합니다. `Deny`는 이미지 표시까지 막습니다.
- 미리보기 HTML은 실행하지 않습니다. DOMPurify로 정리하고 CSP로 스크립트를 제한합니다.
- 미리보기 링크는 웹·메일 주소만 앱이 다시 검사하고 확인 후 기본 앱으로 엽니다.
- Mermaid는 `strict`와 HTML 글자 끄기로 그리고, 결과 SVG를 다시 정리합니다. draw.io SVG는 `<img>`로만 표시해 안의 스크립트가 실행되지 않습니다.

## 이미지와 다이어그램

- 이미지는 `notes/assets/<메모 ID>/`에 저장합니다. 이미지 내용은 메시지 크기 제한을 넘을 수 있어 앱이 클립보드에서 직접 읽습니다. 클립보드 비트맵은 알파값이 0으로 올 수 있어 PNG 형식을 먼저 씁니다.
- 이미지 크기는 대체 글자 뒤에 `|50%`로 적어 다른 Markdown 앱과 호환합니다.
- 쓰지 않는 이미지 정리는 파일 이름을 메모, 휴지통 메모, 복구 기록과 대조합니다. 앱이 저장한 형식이 아닌 파일은 건드리지 않습니다.
- draw.io는 앱에 포함하기에 너무 커서 설치된 Desktop 앱에 맡깁니다. `.drawio.svg`는 그림과 편집 데이터를 함께 담습니다.
- Mermaid는 크기가 커서 해당 블록을 미리 볼 때만 불러옵니다.

## 소스코드 포맷터

메모와 별개인 창(`formatter.html`)입니다. 메모와 같은 Monaco 구성(`monaco-setup.ts`)과 Prettier를 쓰고, 입력은 저장하지 않으며 앱과 메시지를 주고받지 않습니다. Markdown 서식, 미리보기, 이미지 기능은 넣지 않고, 언어 목록에서도 Markdown과 MDX를 뺐습니다.

## 화면 캡처

- UI Automation으로 요소를 찾고, 클릭이 통과하는 강조 창을 띄웁니다. 전역 후크는 세션 동안만 설치합니다.
- 모니터별 DPI는 앱 전체가 아니라 캡처 코드 범위에서만 씁니다.
- 모자이크는 픽셀 자체를 바꿔 저장된 그림에 원본이 남지 않게 합니다.

## 업데이트

GitHub 최신 릴리즈를 확인합니다. draft, prerelease, 다른 호스트, digest 없는 자산은 무시합니다. 크기, SHA-256, 시험 실행을 통과해야 교체하고 사용자가 고를 때만 설치합니다. 코드 서명이 없어 GitHub 릴리즈가 안전하다는 전제로만 위변조를 막습니다.

## 남겨 둔 옛 이름

`.hunmin` 데이터 폴더는 바꾸면 사용자 데이터 이전이 다시 필요합니다. `hunmin.editor.fonts.v1`은 이전 설정을 읽는 호환 키입니다. `window.hunminEditor`와 npm 패키지 이름 `hunmin-notes-editor`도 그대로 둡니다.
