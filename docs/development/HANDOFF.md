# 개발 인계

기록일: 2026-11-01. 기준 기능: `NOTE_WINDOW_REFINEMENTS.md`의 ‘백업·PDF·자동 업데이트’. 릴리즈 빌드 명령은 `README.md`의 ‘릴리즈 빌드’에 있습니다.
이 문서는 상태 기록이며 다음 기능을 자동으로 실행하라는 지시가 아닙니다. 시작할 때 현재 요청·브랜치·차이를 다시 확인하세요.

## 구현한 범위

원래 계획의 작업 1~6: 솔루션·도메인, Markdown/frontmatter 저장소, Monaco 소스 편집·미리보기, WPF WebView2 브리지, SQLite 검색 인덱스, 자동 저장·원자적 저장·크래시 복구를 구현했습니다.

추가 사용자 요청에 따라 언어별 코드 블록 정리, 이름 저장, 트레이 메모 목록·설정·생성, 다중 메모, 최소화 아이콘, X 확인 후 영구 삭제를 구현했습니다. 이는 원래 작업 8·9 일부를 앞당긴 것이며 두 작업 전체가 완료된 것은 아닙니다.

현재 동작은 `NOTE_WINDOW_REFINEMENTS.md`를 따릅니다. 메모 창은 헤더 한 줄과 하단 바 한 줄로 구성하며 기본 크기는 480×640입니다. 이전 문서의 ‘X로 저장 후 닫기’, 화면의 새 메모·이름 변경·글꼴 버튼, 메모 위 설정 모달을 다시 구현하지 마세요. 본문 위 제목 더블클릭은 이름 편집, Windows 제목 표시줄 더블클릭과 최소화는 24px 빈 노란 아이콘, X는 확인 후 휴지통 이동입니다.

## 최근 검증 기록

백업·PDF·자동 업데이트 구현 당시 .NET 213개(Core 18, Bridge 67, Storage 128), 웹 개발·제작 테스트 각 188개, WPF 하네스가 통과했습니다.

- `NOTE_WINDOW_REFINEMENTS.md`: 최신 UI·삭제·최소화·취소 보호.
- `FORMATTING_TRAY.md`: 포맷터·다중 창·트레이 초기 구현과 재실행 명령.
- `TASK_6.md`: 자동 저장·원자적 교체·강제 종료·복구.
- `TASK_5.md`, `../research/SQLITE_SEARCH.md`: 검색 구현·한글 쿼리·인덱스 재구축.

Java WASM과 파서는 앱에 포함합니다. 기존 Monaco 청크 크기와 Java 런타임의 일반 eval 분기에 대한 번들 경고가 있습니다. 실제 Java 정리에 일반 `unsafe-eval`을 허용하지 않았습니다.
